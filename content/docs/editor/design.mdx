---
title: "デザイン"
description: "テーマプリセット、背景、フォント、ボタン、アイコンの形など、ページ全体の見た目の設定。"
---

「デザイン」タブで、ページ全体の見た目を設定します。ブロック単位の色や角丸は [ブロックのスタイル](/editor/blocks/#ブロックのスタイル) で個別に上書きできます。

## プリセット

まずプリセットを選ぶと、背景・文字色・ボタンがまとめて切り替わります。選んだ後に個別の項目を変えると「カスタム」になります。

| プリセット | 雰囲気 |
| --- | --- |
| クリーン | 明るいグレーの背景に黒のボタン（既定） |
| ミッドナイト | 濃紺のグラデーションに白い文字 |
| サクラ | 淡いピンクからクリームへのグラデーション |
| モノクローム | 白背景に黒のアウトライン |
| フォレスト | 深緑のグラデーション |
| ペーパー | クリーム色の紙のような背景 |
| ポップ | 黄色からピンクへの派手なグラデーション |

## 背景

| 種類 | 設定 |
| --- | --- |
| 単色 | 色 |
| グラデーション | 開始色・終了色・角度（0〜360°） |
| 画像 | 画像（アップロードまたは URL）と、文字を読みやすくする暗いオーバーレイの濃さ（0〜1） |

## フォント

Google Fonts から選べます。日本語に対応したフォントには ✓ を付けています。

| フォント | 日本語 |
| --- | --- |
| システム標準 | ✓（端末のフォントを使う。読み込みが最速） |
| Noto Sans JP（既定） | ✓ |
| Zen Kaku Gothic New | ✓ |
| M PLUS Rounded 1c | ✓ |
| Kosugi Maru | ✓ |
| Shippori Mincho | ✓（明朝） |
| Dela Gothic One | ✓（極太） |
| Inter | 欧文 |
| Playfair Display | 欧文（セリフ） |
| Space Grotesk | 欧文 |
| DM Mono | 欧文（等幅） |

欧文フォントを選んだ場合、日本語の文字は端末のフォントで表示されます。

## 色

| 項目 | 内容 |
| --- | --- |
| 文字色 | 本文と見出し |
| 補助の文字色 | 自己紹介やカードの説明文 |
| アクセント | リンクの下線や強調 |
| カードの背景 | リッチリンク・テキストなどカード状のブロックの背景（半透明も可） |

## ボタン

リンクブロックの見た目です。

| スタイル | 見た目 |
| --- | --- |
| 塗り | ボタン色で塗りつぶす |
| アウトライン | 枠線だけ |
| ソフト | 薄い色の塗り |
| シャドウ | 影付き |
| ガラス | 半透明でぼかし |

ボタンの色・文字色と、角丸（0〜999px）を指定できます。

## アイコンとレイアウト

| 項目 | 内容 |
| --- | --- |
| アイコンの形 | 円 / 角丸 / 四角 |
| アイコンの大きさ | 40〜240px |
| 最大幅 | 320〜1200px。ページ本体の横幅の上限。グリッド配置なら 700px 前後が見やすい |
