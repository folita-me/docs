---
title: "制限と上限"
description: "文字数・画像・ブロック数などの上限の一覧。"
---

## アカウント

| 項目 | 制限 |
| --- | --- |
| ユーザー ID | 英数字と `_`、3〜30 文字。予約語（`www` `api` `docs` `admin` など）は不可 |
| 表示名 | 80 文字 |
| 自己紹介 | 1000 文字 |
| ひとことステータス | 60 文字 |
| 独自ドメイン | 1 アカウントにつき 1 つ |
| ソーシャル連携 | プロバイダーごとに 1 アカウント |

## 画像

| 項目 | 制限 |
| --- | --- |
| 形式 | PNG / JPEG / WebP / GIF（SVG は不可） |
| 大きさ | 1 枚 2MB |

## ブロック

| 項目 | 制限 |
| --- | --- |
| ブロック数 | 上限なし（多いほど表示は重くなります） |
| リンク / リッチリンク / 見出しのタイトル | 200 文字 |
| リッチリンクの説明 | 1000 文字 |
| テキスト | 5000 文字 |
| 絵文字 | 16 文字 |
| SNS アイコン | 1 ブロックに 30 個 |
| 表 | 1 ブロックに 30 行（見出し 40 文字・内容 500 文字） |
| タイムラインの件数 | 1 回に 5〜200 件（続きは「もっと見る」） |
| ページとナビ | ナビの項目（ページ + リンク）8 個。ページの名前 20 文字、`#` は 24 文字 |
| URL | 2048 文字。`https:` `http:` `mailto:` `tel:` のみ |
| クラス名（スタイル） | 300 文字。英数字と `- _ : / [ ] . % #` |
| 角丸 | 0〜999px |

## テーマ

| 項目 | 範囲 |
| --- | --- |
| ボタンの角丸 | 0〜999px |
| アイコンの大きさ | 40〜240px |
| 最大幅 | 320〜1200px |
| グラデーションの角度 | 0〜360° |
| 画像背景のオーバーレイ | 0〜1 |

## 計測と連携

| 項目 | 制限 |
| --- | --- |
| アナリティクスの期間 | 7 日 / 30 日 |
| エクスポートの期間 | 30 / 90 / 365 日 |
| Webhook の URL | `https://` のみ、1024 文字。folita 自身・プライベートアドレスは不可 |
| Webhook のタイムアウト | 5 秒 |
| Webhook の自動停止 | 10 回連続で失敗したとき |
| 流入元 | ホスト名のみ、120 文字 |
| タイムラインの同期 | 15 分ごと（今すぐ同期は 1 分に 1 回）。X は直近 7 日を取り直す |
| タイムラインの翻訳（本人以外） | 1 日に既定 10,000 文字（設定 › 便利機能で変更） |
| Threads / pixiv | 1 アカウントまで |
