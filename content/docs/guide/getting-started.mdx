---
title: "はじめる"
description: "アカウントを作ってからページを公開するまでの流れです。5 分あれば公開できます。"
---

<Steps>
<Step>
### アカウントを作る

[accounts.folita.me/signup](https://accounts.folita.me/signup) を開きます。次のどれかで登録できます。

- メールアドレスとパスワード
- Google / GitHub / X / Apple / LINE / Discord のアカウント

メールで登録した場合は、確認メールのリンクを開くとメールアドレスが確認済みになります。
ソーシャルアカウントは後から設定画面で追加・解除できます（[アカウント設定](/guide/account/)）。
</Step>

<Step>
### ユーザー ID（handle）を決める

ユーザー ID は公開 URL（`folita.me/@handle` と `handle.folita.me`）になります。

- 使える文字は英数字と `_`、長さは 3〜30 文字
- 大文字と小文字は区別しません
- `www` `api` `docs` `admin` など、サービスで使う名前は予約されていて取れません

後から変更できますが、変更すると古い URL は開けなくなります。
</Step>

<Step>
### エディタでページを作る

[dashboard.folita.me](https://dashboard.folita.me) がエディタです。左のパネルでプロフィール・ブロック・デザインを編集すると、右のプレビューが公開ページと同じ見た目で即時に更新されます。
詳しくは [エディタ](/guide/editor/) を見てください。
</Step>

<Step>
### 公開する

エディタの「プロフィール」タブにある **ページを公開する** をオンにして **保存** すると、公開 URL で誰でも開けるようになります。
オフにすると、URL を知っていても 404 になります（データは残ります）。
</Step>
</Steps>

<Callout title="ローカルで使う場合">
folita はオープンな PHP アプリです。自分のサーバーで動かすときの手順はリポジトリの `README.md` にあります。
</Callout>
