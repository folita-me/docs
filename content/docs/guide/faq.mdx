title: "よくある質問"
description: "料金、URL、画像、埋め込み、計測についての質問。"
---

<Accordions type="multiple">
<Accordion title="本当に無料ですか？">
はい。ブロック数・カスタム CSS・フォント・アナリティクス・データ連携・独自ドメインを含め、すべての機能に料金はかかりません。
</Accordion>

<Accordion title="folita.me/@yourname と yourname.folita.me は何が違いますか？">
同じページです。好きな方を SNS のプロフィールに貼ってください。`folita.me/yourname`（@ なし）も同じページを開きます。
</Accordion>

<Accordion title="ユーザー ID を後から変えられますか？">
変えられます（[アカウント設定](/guide/account/)）。ただし古い URL は開けなくなるので、SNS に貼った URL も更新してください。
</Accordion>

<Accordion title="ページを一時的に非公開にできますか？">
エディタの「プロフィール」タブで **ページを公開する** をオフにして保存すると、公開 URL が 404 になります。データはそのまま残るので、いつでも再公開できます。
</Accordion>

<Accordion title="アップロードできる画像の形式と大きさは？">
PNG / JPEG / WebP / GIF、1 枚 2MB までです。SVG はスクリプトを含められるため受け付けません。
</Accordion>

<Accordion title="対応していないサービスを埋め込みたい">
埋め込みブロックは YouTube / Spotify / Vimeo / SoundCloud だけです。他のサービスは [リッチリンク](/guide/editor/blocks/#リッチリンクカード) でカードとして紹介するか、[カスタム CSS](/guide/editor/custom-css/) で見た目を整えたリンクにしてください。
任意の `<iframe>` や `<script>` の埋め込みは安全上できません。
</Accordion>

<Accordion title="プレビューと公開ページで見た目が違います">
プレビューは公開ページと同じ HTML をサーバーが生成しているので、通常は一致します。保存を押していない、または公開ページがブラウザにキャッシュされている可能性があります。ページを再読み込みしてください。
</Accordion>

<Accordion title="自分のアクセスも閲覧数に入りますか？">
公開 URL を開けば入ります（エディタのプレビューは入りません）。自分のブラウザで DNT（Do Not Track）を有効にすると計測されません。
</Accordion>

<Accordion title="閲覧者の IP アドレスや個人情報を記録していますか？">
していません。記録するのは、日時・イベントの種類・ブロック ID・参照元のホスト名だけです。詳しくは [アナリティクス](/guide/analytics/) と [プライバシーポリシー](https://folita.me/privacy.html) を見てください。
</Accordion>

<Accordion title="アカウントを削除したい">
現在は設定画面からの削除に対応していません。お問い合わせください。
</Accordion>
</Accordions>
