**folita**（[folita.me](https://folita.me)）は、SNS のリンクや作品をまとめた「プロフィールページ」を作るサービスです。
他のサービスでは有料プランに含まれることが多い機能を、追加料金なしで使えます。

## できること

| 機能 | 内容 |
| --- | --- |
| ブロック | リンク・リッチリンク（カード）・テキスト・見出し・画像・SNS アイコン・埋め込み（YouTube / Spotify / Vimeo / SoundCloud）・区切り |
| 配置 | 縦並び、またはブロックごとに幅と高さを決められるグリッド（Bento 風）。プレビュー上でドラッグして並び替え |
| デザイン | プリセット 7 種、単色 / グラデーション / 画像の背景、Google Fonts 11 種、ボタンスタイル 5 種、角丸・色・アイコンの形・最大幅 |
| カスタム CSS | 公開ページのクラス名（`.folita-*`）と `[data-block-id]` で何でも上書きできる |
| アナリティクス | 閲覧数・ブロックごとのクリック数・流入元。DNT（Do Not Track）を尊重し、IP アドレスは保存しない |
| データ連携 | Google アナリティクス 4 / Meta ピクセルのタグ埋め込み、閲覧・クリックの Webhook（HMAC 署名付き）、CSV / JSON のエクスポート |
| 独自ドメイン | DNS の TXT レコードで所有権を確認して、自分のドメインで公開 |

## 公開 URL

ユーザー ID（handle）を `yourname` にすると、次の URL で同じページが開きます。

```text
https://folita.me/@yourname
https://folita.me/yourname
https://yourname.folita.me/
```

## サービスのホスト

folita は役割ごとにホストが分かれています。ログイン状態は `folita.me` 配下のホストで共有されます。

| ホスト | 役割 |
| --- | --- |
| `folita.me` | トップページと公開プロフィール（`/@handle`） |
| `accounts.folita.me` | ログイン・新規登録・アカウント設定 |
| `dashboard.folita.me` | エディタ・アナリティクス・データ連携 |
| `docs.folita.me` | このドキュメント |

ホストと URL の一覧は [リファレンス › URL とホスト](/reference/) にもあります。
| `<handle>.folita.me` | そのユーザーの公開プロフィール |
