title: "配置とページ（タブ）"
description: "ブロックの並べ方（縦並び / グリッド）と、ページ（タブ）・下バーのナビの作り方。"
---

配置はプレビュー上部の切り替え、または「デザイン」タブの **配置** で変更します。

## 縦並び

すべてのブロックが 1 列に、上から順に並びます。もっとも読みやすく、スマートフォンでも同じ見た目になります。

## グリッド（Bento 風）

2 列のグリッドにブロックを敷き詰めます。ブロックごとに **幅** と **高さ** を決められます。

| 設定 | 選択肢 |
| --- | --- |
| 幅 | 半分（1 列）/ 全幅（2 列） |
| 高さ | 1 行 / 2 行 |

- 「半分」のブロックを 2 つ続けると横に並びます
- 「2 行」にすると、隣の 2 つのブロックと同じ高さになります（画像やリッチリンクを大きく見せたいときに）
- 幅が狭い画面（スマートフォン）では自動的に 1 列になります

## 並び替え

どちらの配置でも、プレビュー上のブロックをドラッグして順番を変えられます。スマートフォンではブロックをロングタップしてからドラッグします。
「ブロック」タブの一覧でも同じ順番で並んでいます。

## ページ（タブ）とナビ

ブロックを複数のページ（タブ）に分けて置き、**下バー** や **上のタブ** で切り替えられます。
ナビにはページのほか、外部サイトへのリンクも並べられます（あわせて 8 個まで）。設定は「デザイン」タブの **ページとナビ** です。

| 設定 | 内容 |
| --- | --- |
| ナビの位置 | **下バー**（画面の下に浮かぶバー）/ **上のタブ**（プロフィールの下）/ **出さない**（最初のページだけ） |
| プロフィールの見出し | **全ページに出す** / **最初のページだけ** |
| アイコンの下に名前を出す | オフにするとアイコンだけ |
| 項目 | ページ: 名前・アイコン・URL の `#`（半角英数字）。リンク: 名前・アイコン・リンク先・新しいタブで開くか |

- ページは「＋ ページを追加」、リンクは「＋ リンクを追加」で足し、← → で並べ替えます。ホームのページは外せません
- ページを外すと、そのページのブロックはホームに移ります
- 「ブロック」タブの上のページの切り替えで、編集するページを選びます。ブロックを追加すると、選んでいるページに入ります（ブロックの **置くページ** でも移せます）
- プレビューのナビを押しても切り替わります。ブロックをほかのページの一覧へドラッグしても移せます
- 公開ページでは `folita.me/@ID#ページの#` で、そのページを直接開けます。ブラウザーの戻る / 進むにも対応しています
- ページが 1 つだけのときは、ナビは出ません

[カスタム CSS](/guide/editor/custom-css/) では `.folita-nav` `.folita-nav--bottom` `.folita-nav--top` `.folita-nav__item`（選択中は `.is-active`）`.folita-panel`（`data-page`）で変えられます。
