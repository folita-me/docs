「ブロック」タブの「＋」から種類を選んで追加します。追加したブロックはプレビュー上でドラッグして並び替えられます。
どのブロックにも共通で **表示 / 非表示**、[グリッド配置](/guide/editor/layout/) のときの **幅・高さ**、[スタイル](#ブロックのスタイル) があります。

## リンク

一番よく使うボタン型のリンクです。

| 項目 | 内容 |
| --- | --- |
| タイトル | ボタンに表示する文字（200 文字まで） |
| URL | `https://` `http://` `mailto:` `tel:` のいずれか |
| 絵文字 | タイトルの左に出す絵文字（省略可） |
| 新しいタブで開く | 既定はオン |

## リッチリンク（カード）

画像と説明文つきのカード型リンクです。作品や記事の紹介に向いています。

| 項目 | 内容 |
| --- | --- |
| タイトル / URL | リンクと同じ |
| 説明 | 1000 文字まで |
| 画像 | アップロードした画像、または画像の URL |
| 新しいタブで開く | 既定はオン |

## テキスト

自由な文章（5000 文字まで）。改行はそのまま反映されます。左 / 中央 / 右揃えを選べます。

## 見出し

セクションの区切りに使う見出し（200 文字まで）。大きさをレベル 1〜3 から選び、左 / 中央 / 右揃えを指定できます。

## 画像

| 項目 | 内容 |
| --- | --- |
| 画像 | アップロード（PNG / JPEG / WebP / GIF、2MB まで）または URL |
| リンク先 | 指定すると画像全体がリンクになる（省略可） |
| 代替テキスト | 画像の説明（省略可） |
| 縦横比 | 自動 / 正方形 / 16:9 / 横長 |

## SNS アイコン

横並びのアイコン列です。1 ブロックに 30 個まで置けます。対応しているサービス:

X (Twitter) / Instagram / YouTube / TikTok / GitHub / note / pixiv / Twitch / Discord / LINE / Threads / Bluesky / Spotify / Web サイト / メール

URL を入れるとサービスごとのアイコンで表示されます。「Web サイト」は任意の URL、「メール」は `mailto:` 形式で指定します。

## タグ

「YouTube 個人」のように、**ジャンル**（大きめの太字）と **カテゴリ** を組み合わせた丸いラベルを並べます。活動しているサービスやジャンルを伝えるのに使います。

- **候補から追加**: ジャンル（Instagram / Twitter / TikTok / YouTube / 17LIVE / SHOWROOM / ツイキャス / Pinterest / 食べログ / Amebaブログ / YOUTRUST など 16 種類）を選び、カテゴリ（個人・音楽・ゲームなど）を押すと追加されます。もう一度押すと外れます
- **自由に入力して追加**: 候補に無いタグも入力できます。ジャンルは省略でき、カテゴリだけのタグにもできます
- 揃え（左 / 中央 / 右）を選べます。1 ブロックに 30 個、ジャンル・カテゴリはそれぞれ 40 文字まで

色はテーマの「カード背景」「文字色」「補助文字色」に従います。[カスタム CSS](/guide/editor/custom-css/) では `.folita-tags` `.folita-tag` `.folita-tag__genre` `.folita-tag__label` で変えられます。
[lit.link から取り込む](/integrations/import/) と、lit.link の活動ジャンルはこのタグになります。

## 埋め込み

動画や音楽のプレイヤーをページ内に表示します。通常の共有 URL を貼るだけで、埋め込み用の URL に変換されます。

| サービス | 貼れる URL の例 |
| --- | --- |
| YouTube | `https://www.youtube.com/watch?v=...` `https://youtu.be/...` |
| Spotify | `https://open.spotify.com/track/...` `.../album/...` `.../playlist/...` |
| Vimeo | `https://vimeo.com/123456789` |
| SoundCloud | `https://soundcloud.com/artist/track` |

YouTube はプライバシー強化モード（`youtube-nocookie.com`）で埋め込まれます。対応外の URL は保存時に空になります。

## フィード

note・Bluesky・YouTube・X の新しい投稿を、ページに一覧で表示します。投稿するたびにページを直す必要はありません。

| 項目 | 内容 |
| --- | --- |
| 取得元 | note / Bluesky / YouTube / X (Twitter) |
| アカウント | 取得元ごとに下の表のとおり。X は入力せず、[連携](/integrations/sources/) している X アカウントを使います |
| 表示する件数 | 3 件 / 5 件 / 10 件 |
| 見出し | ブロックの上に出す文字（省略すると取得元の名前） |

| 取得元 | 入れるもの | 表示される投稿 |
| --- | --- | --- |
| note | ユーザー名（`https://note.com/username` を貼っても可） | 記事のタイトル・冒頭・サムネイル |
| Bluesky | ハンドル（`name.bsky.social` や独自ドメイン。プロフィールの URL でも可） | 本人の投稿と 1 枚目の画像（返信・リポストは除く） |
| YouTube | チャンネル ID（`UC` から始まる 24 文字）かチャンネルの URL | 新しい動画のタイトルとサムネイル |
| X | なし（連携中の X アカウント） | 本人のポストと 1 枚目の画像（返信・リポストは除く） |

- YouTube は、Google の [YouTube を許可](/integrations/sources/#google-のサービスyoutubegoogle-カレンダー) していれば **自分のチャンネルを使う** で ID を入れられます。`youtube.com/@name` 形式の URL には対応していません
- 投稿は folita が一定時間ごとに取り直します（note・Bluesky 15 分、YouTube 30 分、X 1 時間）。すぐ反映したいときは [連携パネル](/integrations/sources/#フィード) の **フィードを取り直す** を押します
- 取得に失敗したときは、前回取得できた投稿をそのまま表示します。一度も取得できていないブロックは公開ページに出ません（理由はエディタのプレビューに表示されます）
- 各投稿と「もっと見る」は、それぞれのサービスのページを新しいタブで開きます。クリックは [アナリティクス](/guide/analytics/) にこのブロックのクリックとして記録されます

<Callout type="info">
X の投稿は X の API で取得するため、X 側の利用枠の都合で取得できないことがあります。
</Callout>

## 区切り

ブロックの間に細い線を引きます。設定項目はありません。

## ブロックのスタイル

どのブロックでも、個別に次を指定できます。テーマ全体の設定は [デザイン](/guide/editor/design/) を見てください。

| 項目 | 内容 |
| --- | --- |
| 背景色 | ブロックの背景 |
| 文字色 | ブロックの文字 |
| 角丸 | 0〜999px |
| クラス名 | [カスタム CSS](/guide/editor/custom-css/) から参照するためのクラス（英数字・`-` `_` など） |

<Callout type="info">
より細かく変えたいときは、各ブロックに付く `data-block-id` 属性をカスタム CSS のセレクタに使えます。
</Callout>
