エディタは [dashboard.folita.me](https://dashboard.folita.me) にあります。画面は **左のパネル** と **右のプレビュー** に分かれています。

## 左のパネル

4 つのタブがあります。

| タブ | 内容 |
| --- | --- |
| ブロック | ページ（タブ）の切り替えと、ブロックの追加・並び替え・編集・削除。[ブロック](/guide/editor/blocks/) |
| プロフィール | 表示名・自己紹介・ひとことステータス・誕生日・アイコン・カバー画像・公開設定 |
| デザイン | テーマ（クラシック / リキッドグラス）、色テーマ、ページとナビ、カラープリセット、背景、フォント、ボタン、アイコンの形、最大幅。[デザイン](/guide/editor/design/)・[ページとナビ](/guide/editor/layout/#ページタブとナビ) |
| CSS | 独自の CSS。[カスタム CSS](/guide/editor/custom-css/) |

## プレビュー

右側のプレビューは、公開ページと **同じ HTML** をサーバーが生成して表示しています。
編集した内容が公開時とずれることはありません。

- プレビュー上のブロックを **クリック** すると、そのブロックが左のパネルで選択されます
- ブロックを **ドラッグ** すると並び替えられます（スマートフォンではロングタップしてからドラッグ）
- スマートフォン（幅の狭い画面）では、上にプレビュー・下にパネルを並べた **分割** 表示になります。上の「分割 / 編集 / プレビュー」で、パネルだけ・プレビューだけにも切り替えられます（選んだ表示はブラウザーに保存されます）
- 「縦並び / グリッド」で [配置](/guide/editor/layout/) を切り替えられます

## 保存と公開

編集内容は、変更してから 1.5 秒ほどたつと自動で保存されます（**保存** ボタンか Ctrl / ⌘ + S でもすぐ保存できます）。保存が済む前にページを閉じようとすると確認が出ます。

公開の切り替えは「プロフィール」タブの **ページを公開する** です。オフの間は公開 URL が 404 になります。

## ひとことステータス

「プロフィール」タブの **ひとことステータス**（60 文字まで）に入れると、アイコンの右上に吹き出しで表示します。空にすると出しません。

## 誕生日

「プロフィール」タブの **誕生日**（任意）で生年月日を登録できます。公開範囲は以下から選べます。

- **年月日を公開**: `2006年9月18日` のようにすべて公開します
- **月日だけ公開**: `9月18日` のように生まれ年を伏せて月日だけ公開します
- **年だけ公開**: `2006年` のように生まれ年だけ公開します
- **非公開**: 登録した誕生日は公開ページには表示しません

月日を公開している場合、誕生日当日（日本標準時）には `Today! 🎉` バッジでお祝いが表示されます。なお、誕生日はアカウント設定（`/settings`）の「アカウント」タブからも確認・変更できます。

## アイコンとカバー画像

「プロフィール」タブでアイコンを設定します。

- **ソーシャルアイコン**: 連携中の Google / GitHub / LINE / X / Discord のプロフィール画像、またはメールアドレスの Gravatar を一覧から選んで取り込みます。画像は folita の CDN に複製されるので、元のサービスで画像の URL が変わっても消えません
- **X の複数アカウント**: [連携パネル](/integrations/sources/) の「つぶやき取得アカウント」で **X で連携** を押して足した X アカウントも、ログインに使っている X と並んで `X @ユーザー名` の候補になります（x.com で別のアカウントに切り替えてから押すと、そのアカウントが足されます）
- **更新**: 一覧の右上の **更新** を押すと、連携中のサービス（足した X アカウントを含む）から最新のプロフィール画像を取り直します（各サービスで画像を変えたあとに使います）。取り直せなかったサービスは、そのサービスでログインし直すか、設定で連携し直す（X アカウントは連携パネルの **X で連携** を押し直す）と最新になります
- **手動アップロード**: PNG / JPEG / WebP / GIF、2MB まで。SVG は使えません

カバー画像（ページ上部の横長の画像）も同じ形式でアップロードできます。

## キーボードで編集する

各ブロックの編集フォームは通常のフォームなので、Tab で項目を移動できます。
テキストブロックの本文は複数行に対応しています。
