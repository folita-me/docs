「デザイン」タブで、ページ全体の見た目を設定します。ブロック単位の色や角丸は [ブロックのスタイル](/guide/editor/blocks/#ブロックのスタイル) で個別に上書きできます。

## テーマ

テーマは **描き方そのもの** を切り替えます（色の組み合わせは下の [カラープリセット](#カラープリセット) で選びます）。
テーマを選ぶと、そのテーマに合う色が入ります。色はその後で自由に変えられます。

| テーマ | 見た目 |
| --- | --- |
| クラシック（既定） | カードとボタンを縦に並べる標準のデザイン |
| リキッドグラス | iOS 26 風のガラス板。背景で淡い色の玉がゆっくり動き、プロフィール・カード・ボタン・下バーがそれを屈折させて映します |

### リキッドグラスの設定

| 項目 | 内容 |
| --- | --- |
| 背景の玉 1〜4 | 背景で動く色の玉の色 |
| ガラスの白さ | ガラス板の白の濃さ（0〜0.9） |
| ぼかし | ガラス越しの背景のぼかし（0〜40px） |
| 屈折の強さ | 縁で背景がゆがむ強さ（0〜60px） |
| プロフィールをガラスのカードに入れる | アイコン・名前・自己紹介をガラスのカードにまとめます |
| 背景に色の玉を出す | 背景画像を見せたいときはオフ |
| 背景の玉を動かす | オフにすると止まります（端末で「動きを減らす」を選んでいるときも止まります） |
| 下バーのレンズ | [下バー](/guide/editor/layout/#ページタブとナビ) の選択中のタブにレンズが乗ります。タップすると滑って移動し、横にドラッグして離したタブに切り替わります |

- 屈折（背景のゆがみと虹色の縁）は Chrome / Edge で表示されます。Safari・Firefox ではぼかしのガラスになります（下バーのレンズの中身は、どのブラウザーでも屈折して見えます）
- カスタム CSS からは `.folita-theme-liquidglass` と、CSS 変数 `--t-orb1`〜`--t-orb4` `--t-tint` `--t-blur` `--t-refraction` で調整できます

## カラープリセット

プリセットを選ぶと、背景・文字色・ボタンがまとめて切り替わります（テーマはそのまま）。選んだ後に個別の項目を変えると「カスタム」になります。

| プリセット | 雰囲気 |
| --- | --- |
| クリーン | 明るいグレーの背景に黒のボタン（既定） |
| ミッドナイト | 濃紺のグラデーションに白い文字 |
| サクラ | 淡いピンクからクリームへのグラデーション |
| モノクローム | 白背景に黒のアウトライン |
| フォレスト | 深緑のグラデーション |
| ペーパー | クリーム色の紙のような背景 |
| ポップ | 黄色からピンクへの派手なグラデーション |

## 背景

| 種類 | 設定 |
| --- | --- |
| 単色 | 色 |
| グラデーション | 開始色・終了色・角度（0〜360°） |
| 画像 | 画像（アップロードまたは URL）と、文字を読みやすくする暗いオーバーレイの濃さ（0〜1） |

## フォント

Google Fonts から選べます。日本語に対応したフォントには ✓ を付けています。

| フォント | 日本語 |
| --- | --- |
| システム標準 | ✓（端末のフォントを使う。読み込みが最速） |
| Noto Sans JP（既定） | ✓ |
| Roboto + Noto Sans JP | ✓（欧文は Roboto。リキッドグラスの既定） |
| Zen Kaku Gothic New | ✓ |
| M PLUS Rounded 1c | ✓ |
| Kosugi Maru | ✓ |
| Shippori Mincho | ✓（明朝） |
| Dela Gothic One | ✓（極太） |
| Inter | 欧文 |
| Playfair Display | 欧文（セリフ） |
| Space Grotesk | 欧文 |
| DM Mono | 欧文（等幅） |

欧文フォントを選んだ場合、日本語の文字は端末のフォントで表示されます。

## 色

| 項目 | 内容 |
| --- | --- |
| 文字色 | 本文と見出し |
| 補助の文字色 | 自己紹介やカードの説明文 |
| アクセント | リンクの下線や強調 |
| カードの背景 | リッチリンク・テキストなどカード状のブロックの背景（半透明も可） |

## ボタン

リンクブロックの見た目です。

| スタイル | 見た目 |
| --- | --- |
| 塗り | ボタン色で塗りつぶす |
| アウトライン | 枠線だけ |
| ソフト | 薄い色の塗り |
| シャドウ | 影付き |
| ガラス | 半透明でぼかし |

ボタンの色・文字色と、角丸（0〜999px）を指定できます。

## アイコンとレイアウト

| 項目 | 内容 |
| --- | --- |
| アイコンの形 | 円 / 角丸 / 四角 |
| アイコンの大きさ | 40〜240px |
| 最大幅 | 320〜1200px。ページ本体の横幅の上限。グリッド配置なら 700px 前後が見やすい |
