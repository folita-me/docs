[dashboard.folita.me/analytics](https://dashboard.folita.me/analytics) で、公開ページの閲覧とクリックを確認できます。
期間は **7 日** / **30 日** を切り替えられます。

## 見られるもの

| 項目 | 内容 |
| --- | --- |
| 閲覧数 | 公開ページが表示された回数（日別） |
| クリック数 | リンク・リッチリンク・画像・SNS アイコンがクリックされた回数。ブロックごとの内訳 |
| 流入元 | 参照元サイトのホスト名（例: `x.com` `instagram.com`）。直接アクセスは「直接」 |

## 計測の仕組みとプライバシー

- 計測は公開ページの JavaScript が `navigator.sendBeacon` で送ります。閲覧者の表示を遅らせません
- ブラウザが **DNT（Do Not Track）** を送っている閲覧者は計測しません
- **IP アドレスとユーザーエージェントは保存しません**。流入元も URL 全体ではなくホスト名だけを保存します
- エディタのプレビューは計測しません

## もっと詳しく分析したい

- Google アナリティクス 4 や Meta ピクセルを使うには、設定の「アナリティクス分析」タブで [計測 ID を設定](/integrations/) します
- 生データが必要なら [エクスポート](/integrations/export/) で CSV をダウンロードできます
- リアルタイムに他のシステムへ流したいときは [Webhook](/integrations/webhook/) を使います
