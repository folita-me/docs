[dashboard.folita.me/integrations](https://dashboard.folita.me/integrations) の **連携** パネルには、連携している Google / GitHub / X / Apple / LINE / Discord のアカウントが「データソース」として並びます。
設定のタブとは別のページです。

## 表示される内容

連携しているサービスごとに、folita が受け取って保存しているデータを表示します。

| 項目 | 内容 |
| --- | --- |
| 名前 | そのサービスでの表示名 |
| ユーザー名 | GitHub の login、X の username など（無いサービスは表示しません） |
| メールアドレス | サービスが提供したメールと、確認済みかどうか |
| プロフィール画像 | エディタの「ソーシャルアイコン」で取り込める画像 |
| 連携日・最終ログイン | 連携した日時と、そのサービスで最後にログインした日時 |
| データの取得 | 最新のデータを取り直せる状態か（下の表） |

| 状態 | 意味 |
| --- | --- |
| 取得できます | 預かっているアクセストークンが有効です |
| 取得できます（自動で更新） | トークンの期限は切れていますが、次の取得時に自動で更新します |
| 再連携が必要 | トークンが無いか失効しています。「連携し直す」で認可し直すと取得できるようになります |

アクセストークンそのものは画面に表示しません。

## 最新のデータを取得

**最新のデータを取得** を押すと、預かっているトークンで各サービスからプロフィール（名前・ユーザー名・画像）を取り直します。
サービス側でアイコンを変えたときに使います。エディタの「ソーシャルアイコン」の **更新** と同じ処理です。

## 連携を追加・解除する

- まだ連携していないサービスは、パネルの下の **連携する** から追加できます。認可が済むと連携パネルに戻ります
- 連携の解除はログイン方法の変更になるので、[アカウント設定](/guide/account/) の「ソーシャル連携」で行います
