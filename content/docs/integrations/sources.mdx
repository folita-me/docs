[dashboard.folita.me/integrations](https://dashboard.folita.me/integrations) の **連携** パネルには、連携している Google / GitHub / X / Apple / LINE / Discord のアカウントが「データソース」として並びます。
設定のタブとは別のページです。

## 表示される内容

連携しているサービスごとに、folita が受け取って保存しているデータを表示します。

| 項目 | 内容 |
| --- | --- |
| 名前 | そのサービスでの表示名 |
| ユーザー名 | GitHub の login、X の username など（無いサービスは表示しません） |
| メールアドレス | サービスが提供したメールと、確認済みかどうか |
| プロフィール画像 | エディタの「ソーシャルアイコン」で取り込める画像 |
| 連携日・最終ログイン | 連携した日時と、そのサービスで最後にログインした日時 |
| データの取得 | 最新のデータを取り直せる状態か（下の表） |

| 状態 | 意味 |
| --- | --- |
| 取得できます | 預かっているアクセストークンが有効です |
| 取得できます（自動で更新） | トークンの期限は切れていますが、次の取得時に自動で更新します |
| 再連携が必要 | トークンが無いか失効しています。「連携し直す」で認可し直すと取得できるようになります |

アクセストークンそのものは画面に表示しません。

## Google のサービス（YouTube・Google カレンダー）

Google のカードの下には、Google の各サービスが並びます。ログインに使う権限（名前・メール・画像）とは別に、
**サービスごとに「許可する」を押したときだけ**読み取りの権限を追加で求めます（段階的な認証）。許可していないサービスのデータは読みません。

| サービス | 許可すると表示されるもの | 求める権限 |
| --- | --- | --- |
| YouTube | 自分のチャンネル（動画数・登録者数）、最新の動画 6 本（非公開・限定公開の表示つき）、プレイリスト 10 件 | `youtube.readonly`（読み取りのみ） |
| Google カレンダー | メインのカレンダーの、これから 14 日間の予定（最大 10 件） | `calendar.events.readonly`（読み取りのみ） |

- どれも読み取りだけで、動画や予定を変更することはありません
- 読み取ったデータは folita に保存せず、連携パネルを開いたときにその場で Google から取得して表示します
- 許可した権限は、普段の Google ログインでも引き継がれます
- 取り消すときは [Google アカウントの「サードパーティ製のアプリとサービス」](https://myaccount.google.com/connections) で folita のアクセスを削除します
- 「許可し直しが必要」と出たら、もう一度「許可し直す」を押してください（この機能より前に連携したアカウントも、一度許可すると使えるようになります）

## フィード

エディタの [フィードブロック](/guide/editor/blocks/#フィード) を置くと、連携パネルの **フィード** に取得元ごとの状況が並びます。

| 表示 | 内容 |
| --- | --- |
| 取得できています / 取得に失敗 / 未取得 | 直近の取得の結果。失敗したときは理由も表示します |
| 最終取得 | 最後に取得した日時 |
| 投稿 | 取得できた新しい投稿 3 件 |

**フィードを取り直す** を押すと、自動で取り直す時間を待たずにすべてのフィードを取得します（1 分以内に取り直したものはそのままです）。
X のフィードは、ここで連携している X アカウントの投稿を、預かっているトークンで読み取ります（読み取りのみ）。

## 最新のデータを取得

**最新のデータを取得** を押すと、預かっているトークンで各サービスからプロフィール（名前・ユーザー名・画像）を取り直します。
サービス側でアイコンを変えたときに使います。エディタの「ソーシャルアイコン」の **更新** と同じ処理です。

## 連携を追加・解除する

- まだ連携していないサービスは、パネルの下の **連携する** から追加できます。認可が済むと連携パネルに戻ります
- 連携の解除はログイン方法の変更になるので、[アカウント設定](/guide/account/) の「ソーシャル連携」で行います
