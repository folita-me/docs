---
title: "インポート（lit.link）"
description: "lit.link の公開ページを、folita のページに取り込めます。"
---

[accounts.folita.me/settings?tab=other](https://accounts.folita.me/settings?tab=other)（設定の「その他」タブ）の「インポート」→ **lit.link から取り込む** を開き、lit.link の公開 URL を入力して **取り込む** を押します。
取り込みが終わるとエディタに移るので、プレビューで確認して必要なら調整してください。

```text
https://lit.link/username
```

`lit.link/username` や `username` だけでも受け付けます。公開されているページを読み取るので、lit.link へのログインは要りません。

<Callout type="warn">
取り込めるのは **自分の** lit.link ページだけにしてください。他の人のページの文章や画像を使うと、権利の侵害になることがあります。
</Callout>

## 取り込まれるもの

| lit.link | folita |
| --- | --- |
| 名前・キャッチフレーズ・アイコン | 表示名・自己紹介・アイコン |
| SNS アイコン | SNS アイコン列（ページの先頭。Twitter と X の同じアカウントは 1 つにまとめます） |
| プロフィール文 | 中央寄せのテキスト |
| ボタン | リンク（画像付きのボタンはリッチリンク） |
| テキスト | テキスト（見出しは 1 行目に入れます。本文中のリンクは「文字（URL）」になります） |
| ピクチャ | 1 枚は画像、3 ピクチャ・4 ピクチャは [画像の横並び](/guide/editor/blocks/#画像の横並び)（3 連・4 連）、スライドは画像の横並びのスライド |
| 動画（YouTube）・音楽（Spotify） | 埋め込み |
| 音楽（Apple Music）・ショップ・カレンダー | リンク |
| 余白 | 見えない区切り線 |
| 活動ジャンル（「YouTube 個人」など） | ページ末尾の [タグ](/guide/editor/blocks/#タグ) |

公開期間を設定していて、今が期間外のリンクは **非表示** のブロックとして取り込みます。
画像は lit.link から folita に複製します（2 MB を超える画像・読み込めない画像は取り込めず、件数を知らせます。取れなかった画像ブロックは、行き先があればリンクとして残します）。

## 取り込み方

- **今のブロックの後ろに追加する**（初期値）: 今のブロックはそのままです。表示名・自己紹介・アイコン・カバーは、まだ空のときだけ入れます
- **今のページを置き換える**: 表示名・自己紹介・アイコン・カバー・ブロックを lit.link の内容にします。今のブロックは消えます

## デザイン

**背景・フォント・文字色・ボタンの色と形も取り込む** をオンにすると（初期値）、テーマを lit.link の見た目に合わせます。

- 背景: 画像（背景動画はそのサムネイル画像）・グラデーション・単色
- フォント: 近いもの（Noto Sans JP / M PLUS Rounded 1c / Kosugi Maru / Shippori Mincho）
- 文字色、ボタンの色と形（角丸・枠線・影）

テキストのカード（半透明の背景と角丸）やアイコンの白い縁は、[カスタム CSS](/guide/editor/custom-css/) に `/* lit.link-import:start */` 〜 `/* lit.link-import:end */` の範囲として足します。
もう一度取り込むと、この範囲だけが新しい内容に置き換わります。

<Callout type="info">
lit.link のアクセス解析、背景動画そのもの、フォントサイズ、ロゴなどは取り込みません。lit.link のページの仕組みが変わると取り込めなくなることがあります。
</Callout>
