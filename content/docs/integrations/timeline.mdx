[dashboard.folita.me/integrations](https://dashboard.folita.me/integrations#tweets) の **連携 › つぶやき取得アカウント** で、集めるアカウントと公開範囲を設定します。
集めた投稿は、エディタの [タイムラインブロック](/guide/editor/blocks/#タイムライン) で公開ページに並べます（どの取得元を出すか・いいね数や翻訳を出すかはブロックごとに選べます）。

[フィードブロック](/guide/editor/blocks/#フィード) との違い:

| | フィード | タイムライン |
| --- | --- | --- |
| 取得元 | note / Bluesky / YouTube の動画 / X | X（サブアカウント・鍵アカウントも）/ Bluesky / Threads / note / YouTube のコミュニティ投稿 / pixiv |
| 件数 | 10 件まで | 集めた投稿をすべて保存し、「もっと見る」または無限表示でさかのぼれる |
| 表示 | タイトルと本文の冒頭 | スレッド・引用・画像・GIF・投票・位置情報・いいね数・翻訳 |
| 公開範囲 | 公開の投稿だけ | アカウントごとに「全員に表示 / 自分にだけ表示 / 表示しない」 |

## アカウント

| 取得元 | 追加のしかた | 集めるもの |
| --- | --- | --- |
| X | **X で連携**。x.com でいまログインしているアカウントを追加します。サブアカウントや鍵アカウントは、x.com でそのアカウントに切り替えてから押してください | ポスト・返信・リポスト・引用、添付の画像・GIF・動画のサムネイル・投票・位置情報、いいね・リポスト・返信・表示回数。返信先・引用元のカード、@メンション（設定したとき） |
| Bluesky | ハンドル（`name.bsky.social`）か DID を入力 | 投稿（返信・リポストを除く）と画像、いいね・リポスト・返信の数 |
| Threads | **Threads で連携** | 投稿と自分のスレッドへの返信、画像・動画のサムネイル・投票 |
| note | ユーザー名かプロフィールの URL | 記事のタイトル・冒頭・サムネイル |
| YouTube | チャンネル ID かチャンネルの URL（Google で YouTube を許可していれば **自分のチャンネルを使う**） | 「投稿」タブのコミュニティ投稿と画像、高評価の数 |
| pixiv | ユーザー ID かユーザーページの URL | イラスト・マンガの作品（R-18 は載せません） |

ここに登録したアカウントは、エディタの [フィードブロック](/guide/editor/blocks/#フィード) の取得先としても選べます。

- ログインに使っている X アカウントは連携しなくても読めますが、相互フォローの判定（下記）には **X で連携** が必要です（フォロー関係を読む権限 `follows.read` を追加で求めます）
- pixiv は、新しいアカウントだとログインしていないと作品一覧が空で返ることがあります。そのときはブラウザの pixiv.net の Cookie `PHPSESSID` を登録してください（暗号化して保存します）
- アカウントごとに **同期する** をオフにすると、そのアカウントの投稿を取りに行かず、公開ページにも出しません。**外す** と集めた投稿も消えます

## 同期

- 公開ページが開かれたとき、前の同期から 15 分たっていれば新しい投稿を取りに行きます（X の API の利用枠に合わせた間隔です）
- **今すぐ同期** はアカウントごと・全体で押せます（1 分に 1 回まで）。公開ページでも、ログインしている本人には同期のボタンが出ます
- 直近 7 日のうちに取得元で消した投稿は、次の同期で公開ページからも消えます。X はそれより前に消したポストも 1 日 1 回照合します
- 画像は folita に複製して配信するので、元のサービスで URL が変わっても表示が消えません
- 投稿者がセンシティブ設定にしたメディア（X の設定、Bluesky の成人向け・性的・ヌード・生々しいメディアのラベル）は、ぼかして「表示」を重ね、閲覧者がタップするまで見せません
- 取得に失敗したアカウントは、理由を連携パネルに表示します。前に集めた投稿はそのまま表示します

## 表示範囲

| 設定 | 内容 |
| --- | --- |
| アカウントの公開範囲 | **全員に表示** / **自分にだけ表示**（folita にログインしているあなたにだけ見える）/ **表示しない**。既定は、鍵アカウントが「自分にだけ表示」、それ以外が「全員に表示」 |
| 鍵アカウントの公開範囲 | 鍵アカウントをまとめて同じ公開範囲にします |
| 始点が別アカウントのスレッド | ほかの人の投稿から始まった会話への、自分の返信 |
| @メンションされた投稿 | 自分の X アカウント宛てのほかの人の投稿。「表示しない」の間は取り込みません |
| 相互フォロー以外からのリプライを出さない | @メンションされた投稿のうち、相互フォローの人のものだけを出します。フォロー関係は 1 日 1 回取り直すほか、メンションしてきた人のぶんは同期のたびに更新するので、新しく相互フォローになった人の投稿も次の同期で出ます |

引用カード・返信先のカードも、元が鍵アカウントなら本人（と「全員に表示」にした自分の鍵アカウント）のときだけ出します。

## 翻訳（DeepL）

設定は [accounts.folita.me/settings?tab=tools](https://accounts.folita.me/settings?tab=tools) の **設定 › 便利機能** にあります。
日本語以外の投稿は、fastText で言語を判定して DeepL で日本語に訳します。公開ページでは投稿ごとに「原文を表示 / 翻訳を表示」を切り替えられ、閲覧者は表示設定で言語ごとに自動翻訳のオン・オフを選べます。

| 設定 | 内容 |
| --- | --- |
| 日本語以外の投稿に訳を付ける | オフにすると訳も翻訳バーも出しません |
| 閲覧者が訳の言語を選べる | 英語・中国語など DeepL が対応する言語に訳して読めます。画面に見えている投稿だけを訳します |
| 本人以外が 1 日に訳せる文字数 | 閲覧者が日本語以外を選んだときに新しく訳す文字数の上限（既定 10,000 文字） |
| DeepL の認証キー | 自分の [DeepL API](https://www.deepl.com/ja/pro-api) のキーを登録すると、それで訳します（Free 版は末尾が `:fx`）。使用量のメーターも出ます |

- 訳は、同じ文なら folita の中で共有します（同じ投稿を何度も訳しません）
- 公開ページでは、本人だけが翻訳メニューの **翻訳を再試行** から「〇〇語として翻訳」を選んで訳し直せます（言語の判定を間違えたとき）
- 翻訳メニューの **言語判定情報** で、fastText の判定（上位 3 言語と確率）と DeepL の判定を確認できます

## 閲覧者の表示設定

公開ページのタイムラインの右上の設定ボタンから、閲覧者が次を選べます。folita にログインしている閲覧者は、設定がアカウントに保存されてほかの端末と同期されます。

- 表示する投稿の種類（投稿 / 返信 / リポスト / 引用）。既定はブロックの設定
- 時刻表記（相対 / 絶対。日時を押すと 1 件ずつ切り替えも可）
- 投稿者の表示（名前 / ID。同時には出さず、名前か ID を押すと 1 件ずつ切り替えも可）
- 入れ子の引用をどこまで展開するか
- 訳の言語・言語ごとの自動翻訳・訳文を少しずつ表示する（お遊び機能）
