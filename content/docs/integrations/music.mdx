---
title: "ミュージック取得アカウント"
description: "Apple Music / Spotify から楽曲を取り込み、Last.fm の「Now Playing」を出します。"
---

[dashboard.folita.me/integrations](https://dashboard.folita.me/integrations#music) の **連携 › ミュージック取得アカウント** で、
公開ページの「音楽ライブラリ」ブロックに並べる楽曲を取り込みます。

## 楽曲をインポート

| 項目 | 内容 |
| --- | --- |
| サービス | Apple Music / Spotify |
| 入れるもの | 楽曲の URL、JSON、CSV、TSV。Apple のライブラリ JSON・Spotify の拡張再生履歴 JSON も読めます |
| ファイル | 10MB まで。ZIP は展開して楽曲のファイルを選んでください |

**内容を確認する** を押すと、何曲が新しく増えて、何曲に情報が補われるか、再生回数やいいね・プレイリストを一覧で出します。
そのうえで **この内容で取り込む** を押すと保存します。

- 同じ曲（同じ識別子）がすでにあるときは、空いている項目だけを補います
- 曲名とアーティストが同じでも識別子が違う曲は、別の曲として追加します（一覧に注意書きが出ます）
- カバー画像は folita に複製して `cdn.folita.me` から配信します。元のサービスで URL が変わっても画像が消えません

## 取り込める再生の状況

書き出したファイルに入っていれば、曲の情報といっしょに次も取り込みます。公開ページの並び替え・絞り込みに使えます。

| 項目 | どのファイルから |
| --- | --- |
| 再生回数 | Apple のライブラリ（`Track Play Count`）、Apple の再生履歴 CSV（1 行 = 1 回）、Spotify の拡張再生履歴（30 秒以上の再生を 1 回） |
| いいね | Apple のライブラリ（お気に入り）、Spotify の `YourLibrary.json`（保存済みの曲） |
| 最後に聴いた日 | Apple のライブラリ（`Last Played Date`）、Spotify の拡張再生履歴（いちばん新しい再生） |
| プレイリスト | Spotify の `Playlist1.json` など、Apple の `Playlist.json`（すでに取り込んだ曲に名前を足します） |

- 同じファイルを何度取り込んでも、再生回数は増えません（多い方を残します）。複数のファイルに分かれた再生履歴は、足し合わせます
- Apple のプレイリストは曲の ID しか持たないので、先にライブラリの書き出しを取り込んでおいてください

## 並び替えと絞り込み

公開ページの音楽ライブラリの上に、閲覧者が使える並び替えと絞り込みが出ます。

- 並び替え: セクション順（既定）/ 再生回数が多い順 / 最近聴いた順 / いいねが先 / 評価が高い順 / 追加が新しい順 / 曲名順
- プレイリストで絞り込み（取り込んだプレイリストがあるときだけ）
- **いいねした曲だけ**（いいねの曲があるときだけ）

セクション順以外を選ぶと、セクションの見出しを外して 1 つの並びで表示します。

## Last.fm のユーザー名

Last.fm のユーザー名を入れると、音楽ライブラリの上に **Now Playing**（いま聴いている曲、なければ最後に聴いた曲）を出します。
空にして保存すると出しません。

## 曲の追加・編集

1 曲ずつの追加・編集、セクションとラベルの管理は、公開ページの音楽のタブから行います（本人にだけボタンが出ます）。
