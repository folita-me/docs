title: "アカウント設定"
description: "ユーザー ID、表示名、メールアドレス、パスワード、ソーシャルアカウントの連携。"
---

設定は [accounts.folita.me/settings](https://accounts.folita.me/settings) です。各項目の **変更 ›** を押すと編集画面になり、保存すると一覧に戻ります。

## ユーザー ID（handle）

公開 URL になる ID です。英数字と `_`、3〜30 文字。変更すると古い URL（`folita.me/@old` と `old.folita.me`）は開けなくなり、他の人が取れるようになります。
使えるかどうかは入力中にその場で確認されます。

## アカウント名

エディタで設定する **表示名** とは別の、アカウントの名前です。公開ページには出ません。

## メールアドレス

変更すると新しいアドレスに確認メールが届きます。パスワード再設定のメールもここに届くので、受け取れるアドレスにしてください。

## パスワード

メール＋パスワードで登録した場合に変更できます。ソーシャルアカウントだけで登録した場合は、パスワードを設定するとメールでもログインできるようになります。

忘れたときは [パスワードの再設定](https://accounts.folita.me/sessions/forgot_password) から、メールで届くリンク（1 時間有効）で新しいパスワードを設定します。

## ソーシャルアカウントの連携

Google / GitHub / X / Apple / LINE / Discord を連携できます。各プロバイダーにつき 1 アカウントです。

- **連携する**: ログイン方法が増えます。連携したサービスのプロフィール画像は、エディタの「ソーシャルアイコン」から取り込めます
- **解除する**: 最後のログイン手段（パスワードも他の連携もない状態）は解除できません

## ログアウト

設定画面の一番下、または [accounts.folita.me/logout](https://accounts.folita.me/logout) からログアウトします。
ログイン状態は `folita.me` 配下のすべてのホストで共有されているので、どこでログアウトしても全体に反映されます。

## 独自ドメイン

「独自ドメイン」タブは [独自ドメイン](/custom-domain/) を見てください。
